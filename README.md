# Nicolás Ferraro

Backend engineer in Buenos Aires (UTC-3). I build document processing and data ingestion pipelines on AWS for financial and tax workflows: bank statement parsing, automated extraction from government tax portals, multi-provider invoice aggregation.

Before backend I spent five years shipping Unity games, including release management and LiveOps for a strategy title with 10M+ downloads.

## What I work on

- Python / Django services on AWS (ECS, Aurora, S3, EventBridge), provisioned with Terraform and deployed with GitHub Actions
- Turning messy inputs (PDFs, Excel exports, government portals) into structured data other teams can rely on
- LLM integration where it earns its place, mostly extraction and classification inside document pipelines

Most of that work is private. The repos below are the public side.
